# 🏃 Real Life Track 3.0

> App de saúde completo com foco em **experiência nativa mobile**, combinando tracking automatizado, IA avançada e comunidade.

![Version](https://img.shields.io/badge/version-3.0.0-purple)
![Platform](https://img.shields.io/badge/platform-iOS%20%7C%20Android-blue)
![License](https://img.shields.io/badge/license-MIT-green)

---

## 🎯 Funcionalidades Principais

### 📱 Módulos de Saúde
- 🚶 **Atividade Física** - Passos nativos, calorias, distância
- 🍎 **Nutrição** - Scanner de alimentos, macros, água
- 💪 **Exercícios** - Academia, cardio, yoga
- 😴 **Sono** - Qualidade, horas, alarmes
- 🩸 **Ciclo Menstrual** - Calendário, sintomas, fertilidade
- 🚽 **Saúde Digestiva** - Urina, fezes (escala Bristol)
- 💊 **Medicamentos** - Lembretes, listas
- 🧠 **Bem-estar** - Humor, estresse, gratidão

### 🤖 Inteligência Artificial
- Comandos de voz para registro
- Scanner de foto (IA analisa prato)
- Insights personalizados
- Chatbot de saúde

### 👥 Social
- Convidar amigos
- Leaderboards
- Desafios em grupo
- Compartilhar conquistas

---

## 🛠️ Stack Técnica

| Tecnologia | Uso |
|------------|-----|
| **Expo SDK 52** | Framework React Native |
| **TypeScript** | Linguagem |
| **Firebase** | Auth, Database, Analytics |
| **HealthKit/Google Fit** | Dados de saúde nativos |
| **Gemini API** | Inteligência Artificial |
| **Capacitor** | Empacotamento nativo |

## 📦 Instalação

```bash
# Clone o repositório
git clone https://github.com/minorfurymusic/Real-Life-Track-3.0.git
cd Real-Life-Track-3.0

# Instale as dependências
npm install

# Execute no Android
npm run android

# Execute no iOS (macOS only)
npm run ios

# Execute no Web
npm run web
```
